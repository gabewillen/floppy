# Project rules

These conformance rules apply to human and AI contributors alike and are
consistent with the full rule set in [AGENTS.md](../../AGENTS.md).

- The official W3C SCXML IRP manifest and `.txml` corpus MUST be the conformance source of truth and development oracle. Local synthetic or bespoke fixtures MAY test the harness but MUST NOT replace the selected official corpus, be labeled as official passes, or support a completion claim.
- Every applicable selected official mandatory case MUST remain discoverable and receive an actionable disposition. `Unsupported`, `Invalid`, `HarnessError`, and `Failed` are Not Passing gaps, not acceptable terminal completion; completion requires every applicable selected mandatory case to be `Passed` for an exact recorded corpus identity. A case is not applicable only when the W3C itself declares so for the prepared data model, or when its W3C assertion and upstream test document fix a different data model so that the prepared specialization never exercises its own, recorded with quoted evidence in the checked-in digest-bound errata file and reported as `NotApplicable`; upstream template or source defects MAY be corrected only by such digest-bound errata, and passes under an erratum MUST be reported as such. Cases the W3C manifest marks as manual MUST always run and MUST NOT be skipped; the mandatory manual cases 178, 230, 250, 301, 307, and 415, which cannot emit an `Outcome` of `pass`, are decided only by the documented manual-equivalent oracle (`crates/scxml-conformance/src/manual_oracle.rs`; optional manual case 513 by the manual-equivalent oracle in `crates/scxml-conformance/src/external_client.rs`) that checks exactly what the quoted W3C manual instruction asks a human to verify; reports record `oracle: manual-equivalent` for them and bind the oracle table version into the report identity, and each stays Not Passing until its real run satisfies that oracle.
- Normal tests and conformance runs MUST NOT implicitly download the corpus. Acquisition and XSLT preparation MUST occur through an explicit reproducible prepare command with recorded source, revision, digest, transformer, template, and output identities.
